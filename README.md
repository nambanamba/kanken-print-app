# 漢検7級 練習アプリ

日本漢字能力検定 **7級**（小学4年修了程度・対象漢字642字）の練習用アプリです。
**印刷して手書き**する練習と、**選択式の問題**、**進み具合の見える化**を1つにまとめています。

受検日を設定すると、**残り日数から逆算して**その日の分量を決めます。

## 使い方

`index.html` をブラウザで開くだけです。サーバーは要りません。

| タブ | 中身 |
|---|---|
| **おうえん** | 受検日まであと何日／できるようになった字／予想得点（合格ライン付き）／分野べつの伸び |
| **きょう** | 今日の問題。選択式はその場で正誤、書き取りは「書ける／あやしい」を選ぶ |
| **きろく** | 紙に書いた分の採点。**既定は全部〇。まちがえた番号だけタップ** |
| **せってい** | 受検日など |

「あやしい」と答えた字が10個たまったら、その日は終わりです。
その10字で**練習プリント（A4）**を印刷できます。

## 設計の考え方

- **できている字は出しません。** 期日までの時間は限られているため
- **「あと◯字」ではなく「あと◯点」で言います。** 字の読み書きだけでは合格点に届かないため
  （読み30＋書き取り40の70点に対し、音訓・画数・部首など**別の知識で80点**）
- **連続日数（ストリーク）を使いません。** 途切れた瞬間に責める装置になるため
- **未実施の分野は0%ではなく「まだ」**と表示します

## データの出典

漢字マスタ（`kanken-kanji.js`・642字）は、次の一次資料から作成しています。

| 項目 | 出典 |
|---|---|
| 級・学年 | 日本漢字能力検定協会「級別漢字表」（2020年新配当対応） |
| 音読み・訓読み・例語 | 文化庁「常用漢字表」（平成22年内閣告示第2号） |
| 総画数・部首 | [KANJIDIC2](https://www.edrdg.org/wiki/index.php/KANJIDIC_Project)（Electronic Dictionary Research and Development Group / CC BY-SA 4.0） |
| 学年別の配当 | 文部科学省「小学校学習指導要領」別表「学年別漢字配当表」（2020年度全面実施） |

**検定の問題そのものは含みません。** 問題はマスタから自動生成しています。

## テスト

```
node tools/test_gen.js      生成ロジック
node tools/smoke-test.mjs   実ブラウザでの通し
node tools/shot.mjs         画面と印刷物の撮影
```

ブラウザは **同梱chromium → Edge → Chrome** の順に探します（`tools/browser.mjs`）。
どれで起動したかは実行時の1行目に出ます。
